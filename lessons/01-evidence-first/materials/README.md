# 第一节课件与录屏素材

课程：《用 Python 和 LangGraph 做一个有据可查的资料研究助理》；本节《怎样判断 Agent 的回答有依据？》。不出镜，按18分钟讲稿安排。

## 从这里开始

- `lesson-01.pptx`：10页图片式课件，讲者备注包含相应口播、动作和时间锚点。图内文字/图形不是原生可编辑对象；修改应回到图稿提示重新生成。
- `lesson-01.pdf`：相同10页的静态阅读版。
- `replay.html`：双击后在浏览器打开，完全离线；固定1920×1080画布等比缩放。按1/2/3选择三个场景，→或空格逐步揭示，←退一步，F全屏；“重置观察”隐藏答案。另有真实失败、手工反例和自测。
- `clips/01-normal.mp4`、`02-no-evidence.mp4`、`03-changed-question.mp4`、`04-real-failure.mp4`：四段无声历史回放短片，依次停留在预测、参数、证据、回答状态；适合插入剪辑软件并在原文处暂停讲解。它们不是18分钟完整课。
- `timeline.tsv`：18分钟画面编排，逐条对应讲稿；列出课件页/回放截图、停留秒数与录制提示。不要把四条短片直接首尾相接当作整节课。
- `lesson-01-visual-track.mp4`：按上述时间轴生成的18分钟无声画面底片，便于录制旁白；包含定格阅读，不是18分钟连续API调用。尚无配音、字幕或真人试学，不是可直接发布的最终成片。

配音正文在[逐段讲稿](../SCRIPT.md)，设备/隐私/试读要求在[录屏清单](../RECORDING-CHECKLIST.md)。可以在PPT讲者备注查看当前段口播，也可以打开脚本边录边讲。

## 录制顺序与学习任务

先看到问题并预测，再揭示模型选的参数、工具返回、最终回答。每个场景都要让学员指出一句由原文支持的结论；无资料场景要求说明为什么“当前资料无匹配”不能推出“世界上没有答案”。最后用会话记忆记录完成三问自测，本地写三行即可。

画面始终标注历史真实记录，不请求供应商、不读.env或CC Switch，不需要API Key。最终三场景使用2026-10-17保存的MiniMax-M3记录；型号是历史条件，代码无型号特例。三个问题是独立运行，不是跨请求会话记忆测试。同轮两个工具是逐项执行，不是并行性能证明。预算仍为4轮模型/3次工具。

真实失败来自首次批次验证：空结果后虚构N01且错误描述预算，保留原始答案。另一条“Agent能自动完成所有任务”是手工教学反例，始终单独标注；不可混称模型真实生成。生成图只是教学示意，具体参数、调用ID和原文以回放及原始JSON为准。

## 证据与复现

`source-manifest.json`记录两份原始证据及notes的SHA256，来源仍在课程的evidence和data目录。`browser-check.json`记录24个状态、两种桌面尺寸及手机等比缩放检查。静态图片不是新模型运行证据；本次制作没有重新调用MiniMax。

从本课根目录重新生成回放（仅Python标准库）：

```bash
python3 lessons/01-evidence-first/build_materials.py
```

图稿源和提示在`../slide-deck/evidence-first/`。重新打包图片课件后运行`../export_assets.py`，需要制作端的Pillow；不改变课程运行依赖。

录制工具`../capture_replay.cjs`仅供制作端使用，需要本地Playwright及Chromium；可通过PLAYWRIGHT_MODULE指定已有模块路径。它打开本地页面并生成四段webm，不执行实时模型。MP4由ffmpeg转码；画面底片的输入列表为`timeline.ffconcat`。重新录制时另存版本，避免覆盖人工剪辑成果。
